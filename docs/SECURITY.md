# Безопасность и модель утечек IP

## Цель

Серверы **Claude / Anthropic** не должны получать реальный IP пользователя до того, как VPN подтверждён.

## Что гарантируется

| Сценарий | Claude/Anthropic видят IP? |
|----------|----------------------------|
| Первый заход без VPN | **Нет** — DNR редирект/block до шлюза |
| Старт браузера со старой сессией | **Нет** — ruleset включён по умолчанию |
| Service worker ещё не запустился | **Нет** — статические правила в manifest |
| VPN отключился на открытой вкладке | Запросы блокируются при следующем recheck |
| Успешный вход с VPN | **Да** — VPN-IP (ожидаемо для работы сервиса) |

## Механизмы

1. **Статический DNR ruleset** (`block_claude`, `enabled: true`) — без окна до `init()`
2. **Блок всех типов запросов**, кроме редиректа main_frame на шлюз
3. **Шлюз** выполняет GeoIP до отключения ruleset
4. **Fail-closed** — `unknown` вердикт = блок
5. **Content script** — скрывает страницу и перепроверяет на открытой вкладке

## Кто видит IP при проверке

| Получатель | Видит IP? | Комментарий |
|------------|-----------|-------------|
| claude.ai / claude.com / anthropic.com | **Нет** (до allow) | HTTP/WebSocket не проходят |
| GeoIP-провайдеры (country.is, geojs.io, …) | **Да** | Необходимо для клиентской проверки в браузере |
| Claude после allow | VPN-IP | Нормальная работа через VPN |

GeoIP-запросы идут **только** на разрешённые в `host_permissions` домены, не на Anthropic.

## Что не покрывается

- Расширение **выключено** или **удалено**
- Другие браузеры / приложения вне расширения
- DNS-резолвинг (запросы к DNS-серверам, не к Claude)
- Утечки на уровне ОС (WebRTC, другие процессы) — вне scope расширения
- Пользователь вручную отключает ruleset через devtools (не предусмотрено)

## Рекомендации пользователю

1. Включать VPN **до** открытия Claude
2. Не отключать расширение при работе с Claude
3. Использовать короткий интервал recheck (1–5 с) при нестабильном VPN
4. Убедиться, что VPN не утекает DNS/WebRTC на уровне системы

## Угрозы и mitigations

| Угроза | Mitigation |
|--------|------------|
| Гонка при старте SW | Статические DNR-правила в manifest |
| Stale `allowed` в storage | `init()` всегда `enableBlocking()` |
| API-запросы мимо main_frame | BLOCK для subresource types |
| Частичная загрузка SPA | Content script `document_start` + hide |
| Обфускация списка стран | Снижает trivial bypass, не security boundary |
