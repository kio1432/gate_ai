# BlockAI

Расширение для Chrome, которое **проверяет VPN перед доступом к Claude** и не даёт серверам Anthropic увидеть ваш реальный IP до прохождения проверки.

Версия: **1.0.9**

## Зачем это нужно

Перед открытием `claude.ai`, `claude.com` или `anthropic.com` расширение:

1. Перехватывает навигацию на шлюз (`blocked.html`)
2. Определяет страну по внешнему IP через GeoIP-сервисы
3. Пропускает только если регион **не заблокирован** (по умолчанию — RU)
4. При сомнении или ошибке — **блокирует** (fail-closed)

Сообщение пользователю — про VPN, без упоминания регуляторных ограничений.

## Установка

### Из исходников (рекомендуется)

```bash
git clone https://github.com/YOUR_USERNAME/gate_ai.git
cd gate_ai
npm install
npm run build
```

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. **Загрузить распакованное** → выберите папку `extension/`

### Из ZIP-архива

```bash
npm run pack
```

Распакуйте `blockai.zip` и загрузите папку как распакованное расширение.

> Локальный `.crx` Chrome часто отклоняет (`CRX_REQUIRED_PROOF_MISSING`). Используйте распакованную установку или ZIP.

## Использование

1. Включите VPN в разрешённом регионе
2. Перейдите на `https://claude.ai` — откроется шлюз с автопроверкой
3. После успешной проверки вас перенаправит на Claude
4. На открытой вкладке расширение периодически перепроверяет VPN (интервал настраивается в popup)

### Настройки (иконка расширения)

| Интервал | Описание |
|----------|----------|
| 1 с – 5 мин | Как часто перепроверять VPN на открытой вкладке Claude |

При отключении VPN вкладка снова уходит на шлюз, сетевые запросы к Claude блокируются.

## Сборка

| Команда | Действие |
|---------|----------|
| `npm run build` | Собрать JS в `extension/` (Vite) |
| `npm run pack` | Сборка + `blockai.zip` + `blockai.crx` |

## Ограничения

- Работает только в браузере с установленным и **включённым** расширением
- GeoIP-провайдеры видят ваш IP при проверке (это не Claude)
- DNS-запросы и трафик вне расширения не контролируются
